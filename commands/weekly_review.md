# Weekly Review Command

## Purpose

Review portfolio state, machine load, blocked tasks, completed reports, and operating risks across Aximo Control.

## Inputs

- `dashboards/dashboard.md`
- `dashboards/tasks.md`
- Latest machine status report.
- Latest daily reports.
- Project `STATUS.md`, `TASKS.md`, and `DEVOS.md` files.

## Workflow

1. Confirm repository status.
2. Review task distribution by status.
3. Review project state by priority and owner machine.
4. Review machine warnings and dirty working trees.
5. Review blockers and overdue follow-ups.
6. Recommend the next week's highest-leverage tasks.

## Safety Rules

- Keep recommendations internal by default.
- Do not change project priority or ownership without explicit approval.
- Do not commit, push, or publish unless explicitly requested.

## Expected Output

- Weekly review report or summary.
- Top blockers.
- Machine and project risks.
- Recommended next week priorities.
